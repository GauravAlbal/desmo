# Glance questions

Five-second questions for the three journey maps. Answers are withheld here
and live in `ANSWER-KEY.md`. Score them after the reader has seen only the
handoff maps.

## BUILD

1. How many steps to finish from the start (structural)?
2. Can anything get stuck?
3. Where is this instance now, and what can happen next?

## CHANGE

1. Does an instance created before the change get the new command?
2. Can an existing instance still finish?
3. What changed, and did reachability change?

## RECOVER

1. Where is this operation now?
2. May I resend?
3. What is the safe next action?
