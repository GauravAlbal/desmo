Each remaining gate has a right-sized minimum proof in `validation/dfy/gate-plan.md`. ## Release decision

- **Quiet public alpha** needs IK-00 through IK-13 plus IK-16's release checks. Owner decisions of 2026-11-13: the IK-06 independent review stays an agent review and the IK-13 cold run stays an agent run plus the owner's own read, both stated plainly in the alpha notes; consumer acceptance (IK-10) is narrowed to qualification in scratch and on disposable stores (the live cutover proceeds separately and is not claimed); native Linux x64 (IK-11) is required: the source suite now passes on native x86_64 hardware at `034700c` (`validation/linux/RECORD-linux-x64-native.md`), and so does the packaged-artifact qualification (the release script on Linux and Linux contention numbers are not run). Currently blocked by: the IK-16 release steps (visibility, private vulnerability reporting, registry publication, `LATEST_RELEASE`, cohort), each separately owner-authorized.
- **Promoted launch** additionally needs IK-15. **Comparative superiority language** needs IK-14.
